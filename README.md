# Ride Booking System 🚖

## Overview
Ride Booking System is a Java-based console application developed using Hibernate ORM and PostgreSQL. The system allows users to book rides, manage drivers, handle transactions, and calculate fares based on vehicle types.

## Features

### User Management
- Register User
- View All Users
- Update User Details
- Delete User
- View User by ID
- Wallet Management

### Driver Management
- Register Driver
- View All Drivers
- Update Driver Details
- Delete Driver
- Driver Availability Management

### Ride Management
- Book Ride
- Assign Available Drivers
- Complete Ride
- Cancel Ride
- View Ride Details
- Ride Status Tracking

### Transaction Management
- UPI Transactions
- Wallet Payments
- Transaction History
- Payment Status Tracking

### Vehicle Management
- Bike
- Auto
- Car

## How to Run

1. Clone the repository:
   git clone https://github.com/pravinsargar05/RideBookingSystem.git

2. Configure PostgreSQL database credentials in persistence.xml.

3. Import the project as a Maven Project in Eclipse.

4. Run the main class.
